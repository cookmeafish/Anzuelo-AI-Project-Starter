# Sources (originals)

Original files exactly as received: documents, exports, images, transcripts, saved web pages. Name them
`YYYY-MM-DD <short description>.<ext>`. **They are never edited, moved or deleted.** The PreToolUse hook denies edits,
and moves or deletes the user didn't ask for (REQ: protect-originals). Corrections and summaries go in
`docs/knowledge/`, with a link back to the original here. Private files stay local: don't upload or paste them into
external services unless the user asks.
