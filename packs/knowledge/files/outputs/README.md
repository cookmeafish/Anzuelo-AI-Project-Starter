# Outputs (deliverables)

Reports, plans, briefs, guides, drafts: anything made for the user to use or share. Name them `<name>.md`, then
`<name> v2.md`, and so on. **A delivered file is never overwritten.** The PreToolUse hook denies it unless the user
explicitly asks for an in-place change (REQ: no-overwrite). Every new version is a new file, so earlier versions stay
available. Process: [docs/playbooks/deliverable.md](../docs/playbooks/deliverable.md).
