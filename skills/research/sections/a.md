# Research, section A: From the project

Part of the research skill (SKILL.md): its answer format, section D and Done when apply.

1. Find the files: the knowledge table in `DIRECTORY.md`, then search `docs/knowledge/`, `sources/`,
   `docs/DECISIONS.md` and `docs/STATUS.md` for the key terms.
2. Open and read every file you will cite. Citing a file you didn't open this turn is blocked (REQ: answer-traced).
3. Answer in the answer format, or, when every fact comes from one or two project files, in plain words: "From the
   week 42 export (exports/2026-W42.csv): ..." (hook: research-cited). Cite the file the fact came from, never a
   note you wrote this turn. Lesson: a short sales answer got academic [1]-[4] footnotes, one citing the agent's own
   notes file instead of the export the numbers came from. Keep verified facts apart from inferred, user-reported and
   unresolved ones.
4. Flag stale facts (`volatile: yes` and older than 90 days), conflicts and gaps. Offer **C** instead of guessing.
5. Nothing recorded: say "nothing recorded in the project", then offer **C**.
