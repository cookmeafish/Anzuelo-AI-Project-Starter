# Glossary

The words this project uses in its own way: abbreviations, nicknames, codenames and team terms. Agents look here
before asking what something means, and add each new answer (session-handoff skill). One row per thing; every other
name for it goes in the same row. People get the name they go by and their role, nothing private. Names of products,
brands and companies that may change belong in [names.json](names.json).
