# Trial v29 findings: false alarms, polling and trial wording in the engine

status: done

Round v29 ran quiet: 12 projects on engine a24faf4. Setup was faster (median 15.3 min, v28q 30.9 under load) and
fewer turns were blocked (47%, v28q 73%). It was WORSE on repeated steps (0.18 per turn). Those were re-reads of a
background job's output while it ran (polling), and a plan-format check run again with nothing changed. Each engine cause below gets a
fix with a self-test that fails without it. The usage-quiet fix (runbook-usage.json) is in the chain now.
