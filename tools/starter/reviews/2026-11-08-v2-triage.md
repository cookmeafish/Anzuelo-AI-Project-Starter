## Open conflicts, settled by rule (2026-11-08)

The rule: a v2 design choice is not a user decision unless it cites a dated one. Covered by a dated user decision:
retired, citing it. Not covered: ported, and v2 adapts. Only two dated user decisions in conflict go to the user.

| Conflict | Decision |
|---|---|
| Claims checked by their wording ("pushed", "committed") | Port, narrow form: a push or commit refused or failed this turn, against an answer saying it happened (rule 4, accuracy; no dated decision against it) |
| A line of the engine's own to the user after a send-back | Retired: row 44 (2026-11-07), the user reads each answer once; the agent's short note is the line |
| "Not opened this turn" for cited files | Port, narrowed so the replay's good answers pass (rule 4; the drop cited no user decision) |
| A work turn no runbook fits | Port: rule 2, such work leaves a runbook behind |
| Waivers through the waive command vs one "does not fit" line in the answer | Both hold, no conflict: rule 7 (no record lines, check names or waivers in the answer) and row 42 (2026-11-07, the user is told plainly what is not done). The answer says it in plain words ("Not done: <thing> - <why>"), with no check name or record syntax, and the end check accepts that sentence for the item; the waive command stays for headless runs, outside the answer |
| No draft check offered in an interactive session | Retired: row 44 (2026-11-07), the agent checks its draft before answering |
| Unresolved checks carried to the next prompt | Retired: row 42 (2026-11-07), at most 3 blocks per request, then the user is told plainly |
| A typed rule request on a turn with no work | Port: REQ queued-messages (row 3, 2026-10-17); the request is routed when the agent picks project-rule, whose items then hold |
| 6 old-suite shares crashed under v2 | Fixed in the suite (fc101a1): a missing state file fails one test, not the share; re-sweep for the real total |
| The old suite inside a host project (host-fixtures) | Port as a v2 test that runs in a copy of a host project |
| A project's declared self-test not run by v2 at the end (it ran it itself) | Port, harm 2: the "check after" promise |
