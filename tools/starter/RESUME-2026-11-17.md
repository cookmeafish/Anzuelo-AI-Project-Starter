## Linux notes: what is Windows-only and what must change
- **Kernel pool and leak checks:** `tools/starter/pooltags.ps1`, `tools/starter/leaks.mjs` (paged/nonpaged pool, the
  kernel File-object count via PowerShell CIM), the pool lines in `tools/starter/release/two-chains.sh`, and the leak
  tests in `tools/hooks/selfcheck.mjs` and `tools/hooks/v2/selftest.mjs`. Linux has no such pool: replace with
  `/proc/meminfo` (Slab, SUnreclaim) and open file descriptors, or report-only, and keep the temp-folder checks.
- **PowerShell calls** in 13 engine files (among them `tools/hooks/hooks-main.mjs`, `gates.mjs`, `launchers.mjs`,
  `relay.mjs`, `transcript.mjs`, `fit.mjs`, `v2/guard.mjs`, `v2/lib.mjs`, `selfcheck.mjs`, `starter/leaks.mjs`,
  `two-chains.sh`). Each must skip when `pwsh` is absent or use `bash`; the guard's PowerShell rules stay (a project may
  still use PowerShell) but must not need it to run.
- **`process.platform === 'win32'` branches** in 11 files (`hooks-main.mjs`, `gates.mjs`, `testtmp.mjs`, `v2/guard.mjs`,
  `v2/lib.mjs`, `selfcheck.mjs`, `v2/selftest.mjs`, `starter/leaks.mjs` ...): check each has a working non-Windows path,
  and that tests written only for Windows skip there.
- **`.cmd` launchers** (26 files mention them): the launcher checks and tests expect `.cmd` next to `.sh`; on Linux only
  the `.sh` / executable path should be required.
- **`USERPROFILE`** (5 files): the home folder must come from `os.homedir()` / `HOME`.
- **`windowsHide` and `tools/hooks/hidewin.mjs`:** harmless on Linux; keep.
- **Line endings:** 126 files handle `\r\n`. Keep the reading side (files from Windows clones); check `.gitattributes`
  so a Linux checkout writes LF. Upgrades compare texts LF-normalized, so mixed endings are safe.
- **Paths:** the code joins paths with `path`; the replay fixtures and some messages carry `C:\` examples as text only.
  Recorded transcripts name Windows folders (`C--projects-...`); the session-gate test builds that name from the path,
  which works the same on Linux (`-home-<user>-...`).
- **Release scripts** run under Git Bash today; on Linux they run under bash directly. The copy-first, braces and
  `stop-tests` behaviour stays.
- First thing on Linux: `node tools/hooks/v2/selftest.mjs`, `node tools/hooks/selfcheck.mjs`, `node tools/trial.mjs`,
  `node tools/audit.mjs`; list every failure, and sort it into "Windows-only test" (skip or port) and "real bug".
